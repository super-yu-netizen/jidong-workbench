# 肌动 · 健身减脂与身体成长工作台

强壮不是口号，是每一次训练留下的证据。

## 打开应用

在线版部署在 Cloudflare Pages；相同功能同步至飞书妙搭。已验证的入口见 `docs/DEPLOYMENT.md`。

页面以 390×844 的移动画布打开，直接进入已有 32 条记录的林屿体验档案。源码在本机运行：

```sh
npm ci
npm run build
npm start
```

然后打开 <http://127.0.0.1:5198/>。本机原始交付文件夹另保留双击启动文件。

请使用同一个地址和浏览器继续记录；Cloudflare、妙搭、本机地址和不同浏览器各有独立档案，不会互相同步。可通过设置中的完整数据导出与恢复迁移。首次完整打开 Cloudflare 或本机版本后，程序和原创素材会缓存，断网仍能使用；妙搭运行环境的差异见部署说明。

## 从这几件事开始

1. **今日 → 继续今日训练**：点击每一组右侧的状态，组间打开休息计时；收工时选择全部完成，或仅计已经练完的组。
2. **训练志 → 右下角加号**：选择训练、计划、动作、体重体脂、围度、饮食、饮水、睡眠或个人纪录，三步存入档案。
3. **详情 → 编辑**：改日期、数值或封面，日程、成长统计和相册同步更新。删除需要确认，可以在随后提示中撤销。
4. **成长**：选择本周、本月或自定义时间；点击数字、日期柱或测量点，可以返回来源记录。阶段报告可以导出或存为个人纪录。
5. **相册 → 上传素材**：先选关联记录，在三步表单最后添加图片、录音、PDF或资料，并可替换封面。
6. **头像 → 个人设置**：调整称呼、补水和周训练目标，添加分类、开关应用内提醒，导出或恢复完整数据。

## 数据与提醒

- 全部个人记录和上传素材都保存在当前浏览器，不发送到服务器。清理浏览器数据前，请在设置中导出备份。
- 提醒根据每条记录的下一次日期显示在日程里。关闭应用后不会发送系统通知。
- 内置档案是连贯创作、可直接修改的体验数据。原创场景图均随应用保存，不使用外链图片。
- 实际训练量＝已完成训练里，已勾选组的重量×次数之和。哑铃按每只录入重量计算；采用同一口径看自己的长期变化。
- 同一天的计划及其执行，在今日行动进度里合并计算；训练志与日程仍保留完整的关联对象。

## 项目维护

需要修改时使用 `npm run dev`；重新生成交付版本使用 `npm run build`。`node scripts/serve.mjs` 启动本地交付入口。数据规则验证使用 `node scripts/check-data.mjs`。

Cloudflare 使用已构建文件直接发布：完成 `npm run build` 后，执行 `npx wrangler pages deploy dist --project-name jidong-workbench --branch main`。源码推送与站点发布分开进行，不会仅因推送 GitHub 就自动更新线上版本。

产品规则、实现结构和验收结果位于 `docs/`，原创素材来源说明位于 `public/assets/ASSETS.md`。
