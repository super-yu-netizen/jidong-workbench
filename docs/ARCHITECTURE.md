# 实现结构

PRD 规则已按用户的完整首版要求收口。采用 React + Vite 的本地应用，不接入账户、后台或外部健康服务。

- src/data.js：记录字段、连贯初始数据、派生统计和关联规则；纯数据函数方便独立验证。
- src/storage.js：本地数据库与媒体持久化、导入导出边界。
- src/App.jsx：五个主页面及设置、详情、三步表单、计时、媒体和报告交互。
- src/styles.css：严格移动端画布、品牌排版、状态及动效。
- src/Icons.jsx：原创统一运动线性图标。
- public/assets：原创场景图片、品牌图标与空状态插画；应用不依赖外链图片。
- docs：产品规则、架构、任务和验收结果。

数据流：操作 → 校验 → 关联同步 → 持久化 → 单一状态发布 → 今日/列表/日程/洞察/相册重算。所有数量和曲线从记录派生，避免另外维护不同步计数。

媒体仅由记录引用，详情与列表共用同一 coverId。删除一个记录时保留其他引用的媒体；删除确认说明影响。记录活动绑定 recordId，删除后活动不留死链。训练休息计时使用截止时间，页面切换不会重置。
